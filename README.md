# Calculadora em Python

Uma calculadora simples desenvolvida em Python para praticar conceitos básicos de programação.

## Funcionalidades

- Soma de múltiplos números
- Multiplicação de dois números
- Menu interativo
- Repetição do programa utilizando `while`
- Encerramento da soma utilizando `.`
- Opção para encerrar o programa

## Tecnologias utilizadas

- Python

## Como executar

1. Tenha o Python instalado.
2. Execute o arquivo `main.py`:

```bash
python main.py
